6.1 Semiconductor Main Memory
    1. Organization of Main Memory
      Memory Cells: The basic unit of memory. Each cell stores 1 bit (0 or 1).
      Addressing: Every memory cell has a unique address, which allows the CPU to locate it.
    
    Access Operations:
        Read: Get data from memory.
        Write: Store data into memory.
        Word: A group of bits (usually 8, 16, 32, or 64 bits) accessed together.
    
    Example:
      A memory with 8-bit words and 256 addresses can store 256 × 8 = 2048 bits.

2. DRAM (Dynamic RAM) vs SRAM (Static RAM)
    | Feature | DRAM                       | SRAM                 |
    | ------- | -------------------------- | -------------------- |
    | Storage | Capacitor stores charge    | Flip-flop stores bit |
    | Refresh | Needs refresh every few ms | No refresh needed    |
    | Speed   | Slower                     | Faster               |
    | Cost    | Cheaper                    | Expensive            |
    | Density | High                       | Lower                |
    | Use     | Main memory                | Cache memory         |

Key Points:

        DRAM is used for main memory because it’s cheap and dense.
        SRAM is used for CPU cache because it’s fast.

3. Types of ROM
    | Type   | Description           | Erasable?                     |
    | ------ | --------------------- | ----------------------------- |
    | ROM    | Read-Only Memory      | No                            |
    | PROM   | Programmable Once     | No, programmable once by user |
    | EPROM  | Erasable via UV light | Yes                           |
    | EEPROM | Electrically Erasable | Yes, multiple times           |

Example Uses:

    ROM: BIOS in computers
    EEPROM: Flash memory for storing firmware.

4. Chip Logic
Memory chips contain internal logic for:
        Address decoding → selects correct memory cell.
        Data I/O → reading/writing data.
        Control signals → Read/Write, Enable, Chip Select.
        Diagram Idea: CPU → Address Bus → Memory Chip → Data Bus → CPU

5. Chip Packaging
    Memory chips come in physical packages:
    DIP (Dual Inline Package) – older style.
    SIMM (Single Inline Memory Module) – older RAM modules.
    DIMM (Dual Inline Memory Module) – modern RAM modules.


6.2.1.0. Error Correction
            Memory Errors
                Memory systems can experience errors, which fall into two main categories:
        
        1. Hard Failures (Permanent Errors)
        
            Definition: Permanent physical defects in memory cells.
            Behavior: Affected cells may:
            Become stuck at 0 or 1, or
            Switch erratically between 0 and 1.
        
        Causes:
        
            Harsh environmental conditions (heat, shock, humidity).
            Manufacturing defects.
            Wear and aging over time.
        
        Example: A DRAM cell that always reads 1 no matter what you write is a hard error.
        
        2. Soft Errors (Transient Errors)
        
            Definition: Temporary, random errors that do not damage the memory physically.
            Behavior: Contents of one or more memory cells may be altered unexpectedly.
        
        Causes:
        
            Power supply fluctuations.
            Alpha particles (from radioactive decay of materials in chips or packaging).
            Interesting Fact: Alpha particles are common because almost all materials contain trace amounts of radioactive nuclei.
            Example: A DRAM cell that flips from 0 to 1 due to an alpha particle hitting it is a soft error.
            Once rewritten, the memory works normally again.

  6.2.1.1.0  Error Detection and Correction
    
            Because both hard and soft errors are undesirable:
            Modern memory systems include logic for detecting and correcting errors.
    
    Techniques include:
            
            Parity Bits – Detect single-bit errors.
            Hamming Codes – Detect and correct single-bit errors; detect double-bit errors.
            ECC (Error-Correcting Code) Memory – Used in servers and high-reliability systems to automatically correct errors.
    
    Summary Table:
        | Error Type | Duration  | Cause                               | Correction           |
        | ---------- | --------- | ----------------------------------- | -------------------- |
        | Hard Error | Permanent | Physical defects, wear              | Replace/repair       |
        | Soft Error | Temporary | Power fluctuations, alpha particles | ECC, Hamming, parity |
