6.1 Semiconductor Main Memory
    1. Organization of Main Memory
      Memory Cells: The basic unit of memory. Each cell stores 1 bit (0 or 1).
      Addressing: Every memory cell has a unique address, which allows the CPU to locate it.
    
    Access Operations:
        Read: Get data from memory.
        Write: Store data into memory.
        Word: A group of bits (usually 8, 16, 32, or 64 bits) accessed together.
    
    Example:
      A memory with 8-bit words and 256 addresses can store 256 × 8 = 2048 bits.

2. DRAM (Dynamic RAM) vs SRAM (Static RAM)
    | Feature | DRAM                       | SRAM                 |
    | ------- | -------------------------- | -------------------- |
    | Storage | Capacitor stores charge    | Flip-flop stores bit |
    | Refresh | Needs refresh every few ms | No refresh needed    |
    | Speed   | Slower                     | Faster               |
    | Cost    | Cheaper                    | Expensive            |
    | Density | High                       | Lower                |
    | Use     | Main memory                | Cache memory         |

Key Points:

        DRAM is used for main memory because it’s cheap and dense.
        SRAM is used for CPU cache because it’s fast.

3. Types of ROM
    | Type   | Description           | Erasable?                     |
    | ------ | --------------------- | ----------------------------- |
    | ROM    | Read-Only Memory      | No                            |
    | PROM   | Programmable Once     | No, programmable once by user |
    | EPROM  | Erasable via UV light | Yes                           |
    | EEPROM | Electrically Erasable | Yes, multiple times           |
