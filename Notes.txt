Computer Architecture (the "what"):
Defines the functional behavior—instruction set (ISA), registers, addressing modes. It's like the blueprint or the programmer’s view.

Computer architecture defines how a computer’s components communicate through electronic signals to perform input, processing, and output operations.

It covers the design and organisation of the CPU, memory, storage, and input/output devices.
Describes how these components interact through buses, control signals, and data pathways.
It directly influences the overall speed, functionality, and reliability of a computer system.

Computer Organization (the "how"):
Defines the physical implementation—control signals, microarchitecture, how the hardware actually executes instructions.

    ###      Basic CPU Components (Organization Level)
                    Control Unit (CU): Manages instruction flow, signals, and coordination of CPU components.
                    Arithmetic Logic Unit (ALU): Performs calculations, logic, and bit-shifts.
                    Registers: Key types:
                    Accumulator – holds ALU output
                    Program Counter (PC) – stores next instruction address
                    Memory Address Register (MAR) – holds addresses for memory operations
                    Memory Data Register (MDR) – holds data sent to/from memory
                    Current Instruction Register (CIR) – stores the fetched instruction
                    (Extended: Instruction Buffer Register – holds instructions waiting to be executed)

Chapter 5: Input/Output (I/O) Organization
5.1 Introduction to I/O

        The CPU and memory alone cannot communicate directly with the outside world.
        Input/Output (I/O) devices (keyboard, mouse, printer, disks, etc.) act as intermediaries.
        I/O devices vary widely in speed, format, and control, so special modules are needed to manage them.

5.2 I/O Modules

        The I/O module connects the CPU and main memory to peripheral devices.
        Its main functions:
        Control and timing – coordinates data transfer.
        CPU communication – sends and receives commands and status signals.
        Device communication – controls the actual device operation.
        Data buffering – matches the speed differences between CPU and devices.
        Error detection – detects transmission errors.
5.3 I/O Techniques

There are three main ways to handle input/output:
    
    1️⃣ Programmed I/O
    
        CPU directly controls all I/O operations.
        CPU waits while the I/O operation completes (busy waiting).
        Simple but inefficient.
    
    2️⃣ Interrupt-Driven I/O
        
        The device interrupts the CPU when it’s ready.
        CPU performs other tasks while waiting.
        More efficient than programmed I/O.
    
    3️⃣ Direct Memory Access (DMA)
    
        A special hardware module (DMA controller) transfers data directly between memory and device without CPU involvement.
        CPU is only interrupted once the transfer completes.
        Used for high-speed devices like disk drives.

Q. Why L1 and L2 cache faster than L3 cache?
L1 and L2 caches are faster than L3 because they are closer to the CPU, smaller in size, and simpler in design, whereas L3 is larger, shared, and farther from the processor, making it slower to access.
