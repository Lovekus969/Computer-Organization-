1.What is the difference between computer organization and architecture?
Computer Architecture:

Computer architecture refers to the attributes of a computer system that are visible to the programmer and that have a direct impact on the logical execution of a program.
It includes the Instruction Set Architecture (ISA) — instruction formats, opcodes, registers, data types, memory addressing techniques, and the effect of instructions on registers and memory.

Computer Organization:

Computer organization refers to the operational units and their interconnections that implement the architectural specifications.
This includes hardware details such as the ALU, control signals, data paths, memory hierarchy, and how the CPU is internally structured.

 In Short:
  Architecture = WHAT the system does (programmer’s view)
  Organization = HOW the system is built (hardware implementation)
2. What are the four basic functions that a computer can perform?
A computer performs four fundamental operations:
  1. Data Processing
  Manipulating data to produce meaningful information.
  Examples: arithmetic operations, logical operations.
  
  2. Data Storage 
  Storing data for later use — either temporarily (RAM) or permanently (disk, SSD).
  
  3. Data Movement (Input/Output)
  Transferring data between the computer and the outside world.
  Examples: keyboard input, monitor output, network communication.
  
  4. Control
  Directing and coordinating all other operations.
  The control unit fetches instructions, interprets them, and issues the necessary control signals.

Q4. What is the difference between simple single processor computer and multicore computer structure?
 A simple single-processor computer has only one CPU core that executes one instruction stream at a time. A multicore computer contains multiple CPU cores on the same chip, allowing parallel execution of multiple instructions and higher performance.

Q5. What are major elements of a multicore computer? Define and explain how are they related to each other?
A multicore computer contains multiple CPU cores on the same chip, each with private L1/L2 caches, and all cores share an L3 cache, main memory, I/O subsystem, and an interconnect bus. A coherence mechanism maintains data consistency between cores when they access shared memory. All these components work together to enable parallel processing and faster system performance.

Q8. What are the two general approaches to developing an embedded operating system?
  There are two general approaches to developing an embedded operating system:
  1. Adapt an existing operating system
  An existing OS (such as embedded Linux, Windows CE, or other commercial/proprietary systems) is modified to suit the embedded application.
  2. Design a dedicated embedded operating system
  A new OS is designed and implemented specifically for embedded use.
  Example: TinyOS, widely used in wireless sensor networks.
Q9. Define and explain the techniques used in contemporary processors to achieve speed-up.
   Contemporary processors include a number of techniques designed to increase instruction throughput and overall performance. The   main techniques are the following:
   1. Pipelining
   
   Pipelining breaks instruction execution into multiple stages (fetch, decode, fetch operands, execute, store result).
   The processor overlaps these operations so that multiple instructions are in different stages at the same time—similar to an assembly line.
   This increases throughput because while one instruction is executing, the next instruction is being decoded, and so on.
  2. Branch Prediction
  
  The processor looks ahead in the instruction stream and predicts which branch or sequence of instructions will be executed next.
  If the prediction is correct, the CPU fetches and buffers those instructions early, keeping the pipeline busy.
  Advanced predictors can look several branches ahead, increasing the amount of useful work available to execute.
  3. Superscalar Execution
  
  A superscalar processor is able to issue more than one instruction per clock cycle.
  It achieves this using multiple functional units and multiple parallel pipelines so several instructions can execute simultaneously.
  4. Data Flow Analysis
  
  The processor examines dependencies between instructions (results and operands) to create an optimized schedule.
  Instructions are executed as soon as their data is ready, independent of their original program order.
  This reduces stalls and improves parallelism.
  
  5. Speculative Execution
  
  Using branch prediction and data flow analysis, the processor executes instructions ahead of time, before it is certain they are needed.
  These results are kept in temporary storage until the branch outcome is verified.
  This keeps execution units busy by executing likely-needed instructions
