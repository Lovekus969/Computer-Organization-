Why do we need logical addressing rather than using physical memory addresses?
 Logical addressing is needed because it provides process isolation, memory protection, and flexibility. The CPU generates logical addresses, which the OS and MMU translate to physical addresses. With logical addressing, programs can be relocated in memory, virtual memory can be used, and multiple processes can run safely without interfering with each other. Physical addresses are fixed by the hardware, but logical addresses allow the operating system to manage memory efficiently and securely.

what is the difference between sequential interrupt processing and nested interrupt processing? 
Difference Between Sequential Interrupt Processing and Nested Interrupt Processing 
Sequential Interrupt Processing 
•	In sequential interrupt processing, only one interrupt is handled at a time. 
•	When an interrupt occurs, the CPU disables all other interrupts until the current interrupt service routine (ISR) is finished. 
•	Other interrupts must wait in a queue. 
•	This method is simple but can cause delays if a high-priority interrupt must wait for a low-priority one to complete. 
  
Nested Interrupt Processing 
•	In nested interrupt processing, the CPU allows higher-priority interrupts to interrupt a lower-priority interrupt handler. 
•	When a new, higher-priority interrupt occurs, the processor pauses the current ISR, handles the new one, and then returns to the previous ISR. 
•	This allows faster response to important interrupts. 
•	It requires hardware support and more complex interrupt handling. 

Q. Why is disabled interrupt approach in handling interrupts risky? What challenges does it pose using this method to handle multiple interrupts? 
Disabling interrupts ensures the current ISR runs safely but is risky because it can block all interrupts, miss events, and cause potential system failures while handling multiple interrupts becomes inefficient. 

Q. Why L1 and L2 cache faster than L3 cache? 
L1 and L2 caches are faster than L3 because they are closer to the CPU, smaller in size, and simpler in design, whereas L3 is larger, shared, and farther from the processor, making it slower to access. 



Q. In most computers L1 and L2 cache are faster than L3 cache, then what is the purpose of having a slow cache memory? 
L3 cache is slower but larger and shared, acting as the final caching layer before RAM. It reduces memory access times, supports efficient communication between CPU cores, and prevents performance bottlenecks, especially in multicore systems.

Q. If the processor wants to write something in memory, what will be transferred on the various bus lines? 
When the CPU wants to write data to memory, the following happens on the bus lines: 
➢	Address Bus: The CPU sends the address of the memory location where the data will be stored. 
➢	Data Bus: The CPU sends the actual data to be written to that memory location. 
➢	Control Bus: The CPU activates the Write signal to indicate a write operation, and may also use signals like Memory Enable or Chip Select to activate the correct memory module

Q. The point-to-point interconnection method is a faster way to connect various components. Explain the disadvantages of this method? 
Disadvantages of Point-to-Point Interconnection 
Although point-to-point interconnection provides fast and direct communication between components, it has several disadvantages: 
➢	High Cost: 
o	Each device requires a dedicated connection to every other device, which significantly increases hardware cost. 
➢	Complex Wiring: 
o	The number of wires grows rapidly with the number of devices, leading to complex and bulky wiring that is difficult to manage. 
➢	Scalability Issues: 
o	Adding a new device requires new dedicated connections to all other devices, making the system difficult to expand. 
➢	Limited Flexibility: 
o	Any change in the system configuration requires rewiring or redesigning the connections.
